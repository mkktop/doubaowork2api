# 部署与备份

## 运行环境

支持 Python 3.10+，适用于 Windows、macOS 和 Linux。
服务器导入账号后可以直接请求上游，不需要豆包桌面客户端、浏览器或 Playwright 常驻。
官方账号、模型权限和验证要求仍由豆包决定。

## 本机启动

按根目录 README 创建虚拟环境、安装依赖并设置环境变量，然后运行：

```bash
python -m doubao_work2api
```

默认面板地址为 `http://127.0.0.1:18789/`，模型 Base URL 为 `http://127.0.0.1:18789/v1`。
管理员密码用于面板，API Key 用于模型调用，两者独立。
首次初始化时读取环境变量，后续管理密码、API Key 和运行配置以本地保存值为准。

也可使用 `scripts/start.ps1` 或 `scripts/start.sh`；启动脚本要求依赖已安装。
Python 入口不会自动读取 `.env`，需要在终端或进程管理器中设置环境变量。

## Docker

```bash
cp .env.example .env
# 编辑 .env，设置自己的管理员密码与 API Key。
docker compose up -d --build
```

Compose 自动读取 `.env`。默认仅将端口映射到宿主机 `127.0.0.1:18789`，
容器以 UID 10001 运行，宿主机 `accounts/` 和 `data/` 目录需允许该用户读写。

服务器可以通过 HTTPS 反向代理暴露需要的入口。模型客户端使用 API Key；
面板管理接口使用独立 Cookie 会话，不接受模型 Key 代替管理员认证。
不要将账号目录、数据目录或账号导出文件作为静态资源发布。

## 导入账号

支持在面板粘贴 JSON、批量选择 JSON 文件、官方扫码，以及独立浏览器登录。
Windows 用户可以关闭已登录的豆包工作客户端后点「离线扫描」。
该扫描依赖当前 Windows 用户的 DPAPI，不能在另一台服务器上直接解密原机器的浏览器数据库。
应在本机导出账号 JSON，再在服务器导入。

浏览器登录会在运行网关的电脑上启动独立 Chrome/Edge 临时窗口。
用户自行完成官方登录后，点击「完成登录并导入」；程序校验官方身份和设备上下文，
成功、取消或 5 分钟超时后清理临时资料。无图形桌面的服务器使用扫码或 JSON 导入。

## 数据与备份

| 路径 | 内容 | 备份方式 |
| --- | --- | --- |
| `accounts/*.json` | AES-256-GCM 加密的账号资料 | 与同目录 `.account-vault.key` 一起备份 |
| `accounts/.account-vault.key` | 账号加密密钥 | 丢失后无法解密原账号文件 |
| `data/settings.json` | 密码哈希、Key 哈希和运行配置 | 保留原文件，避免丢失配置 |
| `data/requests.sqlite3` | 请求元数据和历史用量 | 停止服务后备份整个 `data/` 目录，包含可能存在的 WAL 文件 |
| `data/response-replay.key` | 思考和压缩回放加密密钥 | 原密钥丢失后旧回放令牌失效 |
| `data/benefits.json` | 签到计划与提交/回查记录 | 一并保留，避免丢失当日提交状态 |
| `data/routing.json` | 原生会话和大请求预算设置 | 一并保留 |

日志保留 30 天，记录模型、账号标识、Key 标识、状态、时间和用量，不保存提示词、
模型正文或 Cookie。API Key 只保存哈希，完整值仅创建时显示一次。
账号导出的迁移 JSON 包含可读凭证，导入后内部文件重新加密；不要上传这些备份。

## 自动化与错误处理

签到计划默认关闭，使用北京时间；启用后程序需保持运行。
只有官方详情确认今日已签到才显示成功，结果未知时只回查。
若收到 `710010702`，面板显示「需官方签到」；请在官方客户端活动页处理后回查，
本版本不保证纯 HTTP 签到在所有账号上可用。

`710022004` 等人工验证错误会暂停该账号接单。完成官网验证后对指定账号复测，
完整成功结果才清除验证状态；失效凭证需要重新登录导入。
普通限流与暂时故障按冷却设置恢复，不会将所有错误都当成登录失效。

## 开发验证

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
node --check doubao_work2api/web/app.js
node tests/test_web.js
```

GitHub Actions 配置覆盖 Windows、macOS、Linux 与 Python 3.10/3.12；
跨系统结果以实际 Actions 记录为准。本地测试不会自动调用真实账号上游，
Windows 离线扫描的真实环境检查按条件执行。
